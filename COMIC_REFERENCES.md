# Comic Citadel References

## Purpose

Comics are used as supplementary visual evidence for architecture, silhouettes, streets, interiors, technology and district design. They are not treated as automatically identical to animated-series continuity.

## Reference strategy

For every comic reference, record:

- publication/series
- issue number
- page/panel
- Citadel state
- visible architecture
- camera angle
- new details not established in the show
- continuity compatibility
- confidence level

## Continuity rule

A comic panel can strengthen a reconstruction but should not silently overwrite animated-series geometry. Conflicting evidence is retained and explicitly logged.

## Copyright rule

Use links, metadata, descriptions and permitted reference images. Do not place complete copyrighted comic issues/pages into this repository.
