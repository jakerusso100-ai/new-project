## Required capture tags

Each reference should eventually receive:

- `source_type`: episode / official promo / comic / secondary index
- `source_id`: episode, issue, or page identifier
- `state`: original / damaged / rebuilt / destroyed / New Citadel
- `view`: exterior / aerial / street / interior / underground / machinery
- `evidence`: exact geometry visible
- `confidence`: A / B / C / D
- `model_use`: shell / district / landmark / infrastructure / texture / scale
- `notes`: contradictions or assumptions

## Copyright-safe workflow

Use thumbnails/links or other permitted references where possible. Do not bulk-copy complete comic issues or entire episode galleries into the repository. The reconstruction database should remain useful even when an external image is unavailable.
