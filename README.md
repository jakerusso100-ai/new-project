# Citadel of Ricks — Reconstruction Project

A source-grounded reconstruction of the Citadel of Ricks from **Rick and Morty**, using animated-series references, official material, and supplementary comic references.

## Goal

Produce a complete architectural evidence database, master schematic, dimensional specification and ultimately a detailed 3D reconstruction of the Citadel.

## Repository map

- `RESEARCH.md` — reconstruction methodology and evidence hierarchy
- `SOURCE_INDEX.md` — source catalog and evidence policy
- `IMAGE_REFERENCE_INDEX.md` — visual-reference database
- `COMIC_REFERENCES.md` — comic-reference methodology and discovery sources
- `CANON_TIMELINE.md` — Citadel continuity/state timeline
- `ARCHITECTURE.md` — global architecture and geometry layers
- `EXTERIOR.md` — exterior shell and silhouette reconstruction
- `DISTRICTS.md` — district and landmark inventory
- `INFRASTRUCTURE.md` — transportation, utilities, dimensional and waste systems
- `COUNCIL_CHAMBER.md` — Council/government complex
- `MORTYTOWN.md` — Morty district reconstruction
- `SIMPLE_RICKS_FACTORY.md` — industrial landmark reconstruction
- `CITADEL_POLICE.md` — police/militia facilities
- `CITADEL_DESTRUCTION.md` — destruction and reconstruction states
- `RECONSTRUCTION_PLAN.md` — project roadmap
- `MODEL_SPECIFICATION.md` — eventual 3D model requirements

## Canon states

The project tracks the Citadel as multiple states: original, damaged/post-Rickshank, rebuilt/Ricklantis, late President Morty era, destroyed ruins, and the later New Citadel construction attempt.

## Evidence confidence

- **A — Direct:** clearly visible/repeated or unambiguous.
- **B — Strong inference:** supported by multiple compatible references.
- **C — Plausible:** required to connect known spaces but not directly shown.
- **D — Speculative:** completion where canonical evidence is insufficient.

## Current status

**Research foundation: ACTIVE**

The documentation framework and major evidence categories are established. The next major task is the exhaustive reference-by-reference visual catalog, followed by the master schematic.

## Important note on images

The repository indexes and analyzes reference imagery rather than bulk-mirroring complete copyrighted episode galleries or comic pages. External source links are retained so the visual evidence can be traced.
