# Citadel Scene / Shot Evidence Log

Purpose: provide a repeatable record for individual Citadel views. This is an evidence register, not a schematic.

## Required record fields

| Field | Requirement |
|---|---|
| Record ID | Stable unique ID such as `SHOT-S03E07-001` |
| Source | Episode, comic issue, official material, or secondary index |
| Scene | Scene/location identifier |
| Time/Page | Timestamp or comic page/panel when available |
| State | Original / damaged / rebuilt / late / destroyed / New Citadel |
| View | Exterior / aerial / street / interior / underground / machinery |
| Visible structures | Only structures actually visible or directly stated |
| Geometry facts | Shape, adjacency, elevation, entrances, circulation, proportions |
| Relative scale | People, vehicles, doors, streets, buildings, etc. |
| Evidence class | SHOW / COMIC-CANON / OFFICIAL / SECONDARY |
| Confidence | A / B / C / D |
| Unknowns | Anything the source does not establish |
| Cross-links | Other records that confirm or contradict it |

## Evidence discipline

1. A timestamp proves where a feature appears, not its unseen extent.
2. A dialogue statement proves a named function/location only to the extent the statement actually establishes it.
3. Repeated views can upgrade confidence when the same spatial relationship survives changes in camera angle/state.
4. Similar-looking buildings are not automatically identical modules.
5. If no source resolves a relationship, record `UNKNOWN / NOT SHOWN` rather than filling it in.
