## Image handling policy

These images are reference material, not a replacement for the original episodes. Use them to locate and compare source evidence. Do not treat a single promotional/still image as proof of hidden geometry, dimensions, or floor-plan relationships that are not visible.

For the reconstruction database, each image should be classified by:

- source
- episode/state
- view type
- visible evidence
- confidence
- reconstruction use
- unresolved geometry

Where an image becomes unavailable, the associated source/episode record remains the authoritative research record.
