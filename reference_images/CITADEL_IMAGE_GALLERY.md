# Citadel Image Gallery

This is the working visual-reference archive for the Citadel reconstruction. It is intentionally broader than a representative gallery: every useful Citadel-related visual reference located in this research pass is logged here, while the linked episode/comic galleries remain the source indexes for further frame-level capture.

**Important:** Images below are externally hosted reference images embedded by URL. They are not rehosted copies. Source attribution is retained. Where a source is copyrighted or third-party hosted, treat the image as a pointer/reference and use the original episode or licensed source for authoritative capture.

# Evidence rules

Every new image should be classified as:

`source | episode_or_issue | citadel_state | scene/location | view_type | architectural_feature | visible_evidence | confidence | model_use | notes`

An image is **not** evidence for hidden geometry merely because it resembles another shot. Contradictory views remain separate until reconciled. Screenshots can establish visible geometry, material language, circulation and adjacency, but not hidden floor plans or exact dimensions unless the source directly supports them.

# Copyright-safe handling

These images are reference material, not a replacement for the original episodes or comics. Use source links and externally hosted references where appropriate. Do not bulk-copy complete comic issues, episode galleries, or copyrighted production libraries into this public repository. If a particular image becomes unavailable, preserve its source-page record and architectural evidence description rather than inventing a replacement.
