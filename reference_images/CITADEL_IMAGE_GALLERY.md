## Evidence rules

Every new image should be tagged in the reconstruction database with:

- `source_type`
- `source_id`
- `episode_or_issue`
- `citadel_state`
- `view_type`
- `architectural_feature`
- `visible_evidence`
- `confidence`
- `model_use`
- `notes`

An image is **not** evidence for hidden geometry merely because it visually resembles another Citadel shot. Contradictory views must remain separate until reconciled.

## Copyright-safe handling

These images are reference material, not a replacement for the original episodes or comics. Use source links and externally hosted references where appropriate. Do not bulk-copy complete comic issues, episode galleries, or copyrighted production libraries into this public repository. If a particular image is unavailable, preserve its source-page record and architectural evidence description rather than inventing a replacement.
