## Remaining external-source constraints

The following are intentionally **not** rehosted in the public repository:

- Complete episode screenshot galleries.
- Complete comic pages/issues.
- Full production-art libraries.
- Any image whose current host does not provide a stable, clearly reusable direct image URL.

For those cases the repository retains the source/gallery URL and the architectural purpose rather than silently treating the evidence as missing.
